# AeroNova CRM — Lab 3 FSI

CRM de la aerolínea virtual AeroNova para los procesos de **venta de tiquetes** y **check-in**: un dashboard con KPIs y filtros, y un chatbot ("Nova") conectado a un agente de IA en n8n.

Laboratorio Nro. 3 de Fundamentos de Sistemas de Información.
